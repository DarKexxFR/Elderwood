# Elderwood — Fiche de révision

Fiche de révision non officielle du serveur RP **Elderwood** : lore, société magique, créatures et règles, rassemblés sur une seule page avec une recherche instantanée.

👉 **[Consulter la fiche](https://DarKexxFR.github.io/Elderwood/)** · 🃏 **[Réviser en flashcards](https://DarKexxFR.github.io/Elderwood/flashcards.html)**

## Contenu

| Section | Ce qu'on y trouve |
| --- | --- |
| La magie | Écho, Résonance, Flux, Voile, statuts, Magie d'usage et Runomancie |
| Les quatre maisons | Aerwyn, Brumval, Falcon, Venatrix — couleurs, devises, familles |
| Les lieux | Le château, les salles communes, l'île |
| La société magique | AMRU, hiérarchie des familles, Razeball, monnaie |
| Personnages illustres | Les huit figures du lore |
| Chronologie | De 1298 aux événements de 2026 |
| Créatures | Créatures magiques et légendaires |
| Les règles | Narrations, rolls, NLR, zones RPK, obligatoire / interdit |
| Créer son personnage | Ce qui est autorisé et ce qui demande une validation staff |

## Les flashcards

150 cartes réparties en 8 thèmes (magie, maisons, lieux, société, figures, chronologie, créatures, règles), ou toutes mélangées.

- Tirage aléatoire, clic pour retourner la carte
- Marquage « je savais » / « à revoir », score en fin de deck
- Reprise ciblée des cartes ratées
- Raccourcis : `Espace` retourner, `←` `→` naviguer, `1` à revoir, `2` je savais

## Fichiers

- `index.html` — la fiche interactive, page unique, sans dépendance
- `flashcards.html` — les 150 flashcards, page unique, sans dépendance
- `elderwood-fiche.pdf` — la fiche en PDF A4, 10 pages, imprimable

## Mettre en ligne

Settings → Pages → Source : `Deploy from a branch`, branche `main`, dossier `/ (root)`.

## Avertissement

Projet de fan, sans affiliation avec le staff du serveur. Le lore appartient à ses auteurs. En cas de divergence, le site et le règlement officiels font foi.
